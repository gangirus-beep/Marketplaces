Принятый порядок вариантов: полные фото галереи → целые изделия из коллажа → качественные видимые фрагменты с подписью «Фрагменты возможных дизайнов обложек» → увеличенный исходный коллаж, если качественные фрагменты не получаются. Скрытые части не дорисовывать. Для Самсона: один запрос одновременно, пауза >=2 секунд, кэш, остановка при 429 с сохранением Retry-After. Лимиты API не считаются подтверждёнными лимитами сервера фото.
