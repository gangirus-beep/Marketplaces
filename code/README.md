- `cover.html` — шаблон обложки 900×1200: все фоны трёх серий (ключи `line_a` … `passepartout`), цвет плашки, три шрифта заголовка + компактный, тон «подложка под фото», правила стопки. С версии 2 подзаголовок всегда в одну строку (кегль уменьшается до 22 px).

- `axis.py` — ось вытянутости товара (смещение стопки поперёк оси).
- `stage/` — конвейер одного этапа, проверен на этапах 1 и 2 (этап 2: 1 244 обложки за 3 минуты, 451 последнее фото):
  - `extract.py` — карточки и товары типа из базы;
  - `prep.py` — `goods.json` и скачивание кадров U и W;
  - `srcload.py` — `load(код, №)`: кадр поставщика; у товаров с пометкой «slidecrop.py» в «Комментарии по фото» кадр обрезается по контуру товара (`slidecrop.bbox`), товар возвращается прямоугольником; слайд-коллаж (пометка «по каждой из») режется на части по строкам и столбцам. Перед запуском: `cp pass/slidecrop.py .`;
  - `cut.py` — вырезка кадра для обложки (через `srcload`), тон, контактные листы вырезок; `zoomcut.py` — крупный просмотр выбранных вырезок на фоне плашки;
  - `recut_shape.py` — **вырезка «по фигуре»** (замечание владельца 06.10.2026): вместо контура — фигура из прямых линий с заходом в товар на 3–4 px: четырёхугольник по четырём сторонам (`quad`), повёрнутый (`rot`), плотная маска по цвету для непрозрачного цветного товара сложной формы (`tight`), выпуклый многоугольник (`hull`); у коллажей — для каждой части; `keep` — фигура не подошла, осталась прежняя вырезка; у коллажа внахлёст «четыре по углам и одна в центре» — ступенчатая фигура (`steps`: силуэт выпрямляется прямоугольным ядром, выемки между тетрадями остаются фоном) или объединение пяти прямоугольников (`cross`: берётся само, когда у светлой тетради фон проел яму; принудительно — `SHAPE_FORCE={код:'cross'|'steps'}` в `texts.py`). Запускать после `cut.py` для всех товаров белых и прозрачных типов; `sheetcut.py` — листы просмотра вырезок;
  - `recut_combo.py` — **прототип** вырезки «тело по фигуре + лента по цвету» для бейджей с лентой, шнурком, рулеткой (у них `recut_shape.py` даёт `keep` или `hull` с белым фоном внутри петли): `python3 recut_combo.py код …` после `recut_shape.py`; результат `combo:quad|rot|hull` или `content` — смотреть крупно;

  - `recut_rows.py` — повторная вырезка построчно для товаров с белой полосой на самой обложке (в `cut.py` у товара не «ассорти» `ncomp > 1` или `fill < 0.9`);

## Порядок на один этап
Рабочая папка — корень распакованного генератора: `cover.html` ищет шрифты в `fonts/`, вырезки — в `cut/`.

1. `cp stage/*.py .` и `python3 extract.py "<часть названия типа>"` — около 20 секунд на чтение базы.
2. Если проход «в упаковке / поштучно» по типу не сделан — сначала он (отдельная рабочая папка, например `/home/claude/sN`): `extract.py` → `cp pass/*.py` → `dl.py` в фоне (2 700 фото — около 7 минут, 849 — меньше минуты) → `thumbs.py` → `sheets.py` → просмотреть все `sh_NN.jpg` → `zoom_slides.py` и `zoom_sel.py` для слайдов и спорных кадров → `decide.py` по образцу → распаковать базу в `/home/claude/bx` → `spravka.txt` → `patch.py` → `zipcheck.py "<тип>"`. Просмотр 31 листа и запись в базу занимают два ответа: после просмотра выписывать находки в сообщение.
3. `python3 prep.py` → `python3 cut.py` — запускать в фоне через `setsid nohup`: 342 кадра 1500×1500 вырезаются около 5 минут, дольше лимита одной команды → просмотреть `sh_cut_N.jpg`; при разрывах товара — `recut_rows.py`.
4. Написать `texts.py` по образцу: словарь `T[код] = {forms, heading, sub, chips[4], bg, copies?}`, словарь `NOTE`, `BGCODE`, `TONE_FORCE` и параметры этапа (`DATE, STAGE, STAGE_NO, TYPE, ARCH, ACCENT, PLAQUE, FONT, STAGE_COMMENT, NEW_RULES`). Тексты — только из названий, характеристик и описаний поставщика; всю таблицу текстов вычитать.
5. `python3 render.py <2–3 кода>` — проба, затем полный рендер в фоне: `setsid nohup python3 render.py > render.log 2>&1 &` (806 обложек — около 5 минут). `python3 review.py` → просмотреть `rev_N.jpg`.
6. `python3 last.py`.
7. `python3 reg_append.py` (берёт реестр из файлов проекта, пишет новую версию в выдачу) → `python3 pack.py`.

## Правила, зашитые в скрипты
- Историческое правило прежних выпусков: для коллажа «ассорти» использовался `copies=1`. Для новых обложек с 12.10.2026 действует `stage/assorti_rules.md`: отдельно количество одним дизайном и отдельно варианты. Последние фото этим решением не изменяются.
- Фон тетрадей и блокнотов = линовка товара: ключи `line_*`, `narrow_*`, `grid_*`, `big_*`, `oblique_*` с цветом бумаги `a` (классика), `b` (крем), `c` (мята), `d` (небо). Частая косая линия — временно `oblique_a` (Т31); отдельный корректный фон ещё не выбран (проверка 12.10.2026).
- Плашка: «N <товар> в наборе», у типов единицы «набор» и «упаковка» — «в комплекте»; у товара, все карточки которого — квант 1, плашки нет. Свою вторую строку задаёт `line2` в `T[код]` (комплект 404391: `forms='комплект|комплекта|комплектов'`, `line2='по 5 тетрадей'`, `copies=1`).
- Белый товар (тон `panel` из `cut.py`) — тёмная подложка под фото в цвет плашки; принудительно — `TONE_FORCE`.
- В подписях «100 %», «г/м²», «N листов» и номер ГОСТа не разрываются переносом (`NB` в `render.py`).
- Последнее фото: зазор 20 px до 20 единиц, 12 px до 60, 7 px свыше; ровная сетка получает преимущество 1,2.
- Товары с двумя ID ВХ у карточек: имя файла берётся по ID ВХ карточки.

## Что смотреть в проходе (по опыту этапов 1 и 2)
- Главное фото: одна единица анфас, коллаж вариантов («ассорти»), отогнутая обложка, товар под углом, этикетка-вкладыш или бандероль.
- Ровный кадр анфас среди доп. фото — он лучше для стопки и сетки последнего фото. Решение владельца 05.10.2026: если на главном фото товар лежит под углом, а ровный кадр анфас есть, на обложку и последнее фото берётся ровный кадр.
- Этикетка-вкладыш или бандероль на главном фото (решение владельца 05.10.2026): на обложку и последнее фото берётся кадр без этикетки, если он есть (U, W, AB); главное фото с этикеткой остаётся в AA и уходит в доп. фото. Кадр оборота не годится.
- Люди, напечатанные на самом товаре (тетради «Футбол», «Sport Club»): карточки оставляем, в комментарии отмечаем.
- Слайды «Форматы» встречаются в нескольких вариантах изображения: искать по сходству с уже убранными, а не только по контрольной сумме.
- Слайды поставщика с количеством («5 тетрадей»), которое противоречит квантам; слайды с товаром другого цвета; фото с людьми; баннеры бренда.
