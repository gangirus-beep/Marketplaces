# Действующие правила медиаконтента — 13.10.2026

Решение владельца после выбора варианта А. Применяется ко всем категориям. Имеет приоритет над историческими правилами размножения товара на обложке.

## Обложка

- Основное фото показывает одну товарную единицу поставщика независимо от кванта карточки. Штука — одно изделие; набор — весь реальный состав одного набора; упаковка — одна продаваемая упаковка. Нельзя показывать отдельный предмет вместо набора или групповую упаковку вместо продаваемой штуки.
- Товар показывается крупно. Продажный квант акцентируется количественной плашкой, в том числе при кванте 1. Размножение по кванту, плитка и стопка на обложке отменены. Дополнительные ×N поверх фото не добавляются. Название, состав набора и единица плашки согласованы с карточкой.
- Ассорти: основной кадр — один подтверждённый вариант; ниже отдельный блок возможных вариантов. Полные кадры галереи → целые изделия из коллажа → качественные видимые фрагменты с соответствующим заголовком → увеличенный исходный коллаж при невозможности качественных фрагментов. Для наборов с фиксированным составом эта схема случайного ассорти не применяется.
- Для кванта >1 сохраняются две строки: «В комплекте могут быть одинаковые или разные дизайны» / «(без возможности выбора из наличия на складе).». Для кванта 1: «Дизайн без возможности выбора из наличия на складе». У других категорий термин дизайн/цвет адаптировать по товару, сохраняя смысл отсутствия выбора.
- Реальные фото поставщика; не дорисовывать скрытые части, толщину и надписи. Фоны, палитры и шрифты сохраняются, все фоны без полей. JPEG 900×1200; текст вариативности выше 996 px, нижний запас 120 px.

## Последнее фото

- Отдельный файл ID_квант_last.jpg: белый фон #FFFFFF, без добавленного текста и инфографики. Показать фактическое содержимое продажи по кадру W.
- Штучный кадр: число копий = квант. Если одна единица — набор из N предметов, а кадр показывает один предмет, число копий = квант × N; если показывает целый набор, число копий = квант. Не подменять упаковку набором или штукой.
- Небольшие количества — плитка, если экземпляры различимы. Рабочая граница генератора: до 20 показанных единиц. Больше 20 — компактная стопка: небольшой общий сдвиг, крупный передний экземпляр, без длинной гармошки. Для сложных форм раскладку проверять отдельно; при необходимости переключать плитку/стопку, не меняя количество.
- Ограничение 40 копий исторической обложки НЕ переносится на последнее фото. Количество копий считают по содержимому продажи; в плотной стопке слои могут перекрываться и не пересчитываться глазами. Стопка — раскладка реальных исходных фото, не реконструкция толщины или вида сбоку.
- Для случайного ассорти последнее фото не создаётся, W пустая, реестр «НЕТ» — прежнее исключение сохраняется.

## Следующий этап

Сначала контрольный перевыпуск 50 разнообразных обложек тетрадей этапов 1–2. Выборка должна покрыть форматы, линовки, объёмы, кванты, поставщиков, скрепления, типы единицы и все способы блока ассорти. Показать, согласовать; только затем полный выпуск тетрадей. Старые принятые JPEG не удалять до приёмки замен. Не запускать П2 и не перевыпускать другие категории автоматически.

На контрольном этапе обязательны 50 обложек. Последние фото обновлять отдельно после проверки пригодности W и количества; при ассорти не создавать. Старые ZIP 12.10 и точечные 139 замен сохраняются как предыдущие версии, а не как новый выпуск по варианту А.
