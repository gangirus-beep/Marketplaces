# Ассорти — действующие правила 13.10.2026

Общий контракт: ../media_rules.md. На обложке одна товарная единица независимо от кванта; прежняя плитка/стопка основного фото отменена. Количество — в плашке. Для фиксированного набора показывать действительный состав одного набора.

Варианты: отдельные полные фото → целые изделия из коллажа → качественные видимые фрагменты → увеличенный исходный коллаж. Не дорисовывать скрытые части и надписи. Фрагменты имеют заголовок «Фрагменты возможных дизайнов обложек»; у других категорий адаптировать название. Высота 300 px — параметр принятого запасного образца, а не обязательный размер любого коллажа.

Под вариантами при кванте >1 две строки: «В комплекте могут быть одинаковые или разные дизайны» / «(без возможности выбора из наличия на складе).». При кванте 1: «Дизайн без возможности выбора из наличия на складе». Под основным кадром допустима спокойная подпись «Один из возможных вариантов». Нижний запас 120 px, текст вариативности выше 996 px.

Последнее фото для случайного ассорти не создаётся: W пустая, реестр «НЕТ». Прежние согласованные варианты миниатюр остаются действующими. Историческая спецификация 12.10 сохранена отдельно и не задаёт новый основной кадр.
