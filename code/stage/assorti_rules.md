# Обложки «ассорти»: утверждённая компоновка

Версия 14, решение владельца от 12.10.2026. Образец — товар ID ВХ 63197, квант 6. Эти правила имеют приоритет над прежним правилом «коллаж ассорти ставится один раз, copies=1» при подготовке новых обложек.

## Область применения

«Ассорти» означает случайный дизайн или цвет без возможности выбора. Наборы с фиксированными разными цветами внутри не относятся к этой схеме: показывается их действительный состав. Правило относится к обложкам. Последние и дополнительные фото, старые выпуски и реестр этим решением автоматически не меняются.

## Компоновка

1. Сохраняются действующие фон категории, цвет количественной плашки, шрифты и общий стиль. С 12.10.2026 все фоны используются без линий полей; красная вертикальная линия на сохранённом образце отменена. Количественная плашка показывает реальное количество по карточке WB.
2. Основное фото: выбрать один реальный дизайн из фотографий поставщика и размножить его по количеству продаваемых единиц. Для небольшого кванта — различимая плитка; для больших — стопка по действующему правилу (не более 40 видимых копий, полное количество в плашке). Коллаж вариантов не используется вместо изображения количества.
3. На образце 63197_6 — ровно шесть тетрадей одного дизайна, плитка 3 × 2. Выбранный фиолетовый дизайн — пример размещения, не обязательный цвет для всего каталога.
4. Ниже основного фото — отдельный компактный блок «Возможные дизайны обложек» с миниатюрами подтверждённых вариантов. На образце пять вариантов в один ряд. Они не считаются дополнительными единицами комплекта и не обещают наличие каждого варианта. Для других товаров название блока адаптируется по предмету: например, «Возможные цвета».
5. Под миниатюрами две строки, без переноса текста внутри скобок на третью строку:

   В комплекте могут быть одинаковые или разные дизайны
   (без возможности выбора из наличия на складе).

6. Над основным фото НЕ ставить «Пример комплекта. Без выбора дизайна». Не добавлять тревожный красный блок с восклицательным знаком.
7. Нижний запас — 10% высоты (120 px при 900 × 1200), без важных текстов. Это выбранный отступ, а не гарантия защиты от всех ярлыков WB.
8. Менее важные характеристики располагаются ниже блока вариативности. Нижний левый угол допускает перекрытие ярлыками; на образце здесь «Обложка — мелованный картон», справа «Скрепление — скоба, с полями». Все плашки внутри холста, без обрезанного футера.
9. Главный приоритет проверки в превью: ярлыки не перекрывают заголовок блока вариантов и обе строки текста о вариативности. При конфликте сокращать зону основного фото или менее важные характеристики. Характеристики допустимо перекрыть частично.

## Исходные фото и проверка

- Для выпуска использовать фотографии поставщика. Допустимы вырезка, масштабирование, раскладка и копирование одного изделия; нельзя дорисовывать или менять его детали, надписи и рисунок.
- Сначала искать отдельный кадр дизайна. Если есть только коллаж, извлекать полностью видимый экземпляр; скрытые части не восстанавливать генерацией. При отсутствии полноценного исходника требуется отдельное решение по товару.
- Квант считает единицы поставщика. Если одна единица — набор, не подменять число наборов числом предметов: количество и состав показываются согласованно.
- При кванте 1 пояснение об одинаковых/разных дизайнах во множественном числе не подходит; адаптировать к одной единице, сохранив отсутствие выбора. Точная формулировка для таких карточек согласуется при их выпуске.
- Перед выдачей проверять число экземпляров, варианты, целостность фото, оба текстовых ряда и превью с ярлыками в исходном размере.

## Образец и технический статус

`stage/assorti_layout_63197_reference.png` — утверждённый визуальный образец компоновки, созданный при обсуждении с помощью генерации изображений. Его нельзя использовать как источник товарных вырезок: для выпуска нужны оригинальные фотографии.

В версии 16 новый блок реализован в `stage/render_assorti.js`; сценарий `stage/reissue_tetradi_v16.mjs` выпускает тетради по восстановленным исходникам. До 20 экземпляров — плитка, больше — стопка до 40 видимых копий. Квант 1: «Дизайн без возможности выбора из наличия на складе». Проверяются границы текста и нижний запас 120 px. Старый `stage/render.py` сам этот блок не создаёт.
